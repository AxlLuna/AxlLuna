## Cómo trabajo

Casi todo lo que construyo vive detrás de una puerta: plataformas de venta y acceso
para eventos. Ahí un error no se mide en bugs, se mide en gente esperando afuera.
De eso me quedaron tres obsesiones.

**Datos que llegan a tiempo.** Un aforo que se actualiza tarde no es un dato, es una
disculpa.

**Integraciones que no se caen un sábado a medianoche.** El peor momento posible es
exactamente cuando más se usa.

**Mapas que dicen la verdad.** Trabajar con datos geoespaciales me enseñó que una
coordenada mal puesta se ve bien en la base de datos y horrible en la vida real.

<br />

```
uws-geo         typescript   ·  datos geoespaciales
uv-chatbot-gp   javascript   ·  interfaces conversacionales
```
